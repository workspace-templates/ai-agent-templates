## What it does

Much SQLAlchemy code online is still written for version 1.x, and it shows: global sessions, implicit lazy loads and autogenerated migrations committed unread. This skill steers the agent to the 2.0 style.

It focuses on session lifetime, loading strategy for relationships and the review of Alembic output before it reaches a database.

## Use it when

- You are starting or modernizing a SQLAlchemy project
- You see DetachedInstanceError or sessions shared across threads
- A relationship causes N+1 queries
- You need to write or check an Alembic migration

## What it can access

- Reads and edits Python files and Alembic migrations
- Runs tests and may run alembic against a development database
