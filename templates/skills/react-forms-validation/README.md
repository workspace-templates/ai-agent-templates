## What it does

A form is where users give you money or data, and where small flaws cost the most. This skill has the agent build forms that work by keyboard and screen reader, validate with one schema shared by client and server, and survive slow networks.

Errors appear where users can find them, at the right moment, in words that say how to fix them.

## Use it when

- You are adding a signup, checkout or settings form
- A form lets users submit twice or loses input after an error
- Validation rules differ between the browser and the API
- An accessibility audit flagged missing labels or error announcements

## What it can access

- Reads and edits React components, schemas and tests
- Runs your test commands

## Automated checks

- ✅ **No hidden text.** No invisible or direction-changing characters in any file.
- ✅ **No embedded secrets.** No keys or tokens; secrets are read from your environment.
- ✅ **Instructions only.** Plain text for the agent to read. It runs nothing by itself; your agent asks before acting, as usual.
